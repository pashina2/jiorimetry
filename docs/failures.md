# Failures

Same shape as [`facts.md`](facts.md): a row exists only if a file in this repository shows it. A
failure whose evidence was not exported is named under the table as a candidate for a later export,
and nothing more is claimed about it here.

Columns:

* **what was believed** - the assumption the instruments were built on.
* **evidence** - the file that shows otherwise, then the literal string in it.
* **what changed** - the file or rule in this repository that changed because of it.
* **how to reproduce** - a command that runs inside this repository, or `recorded only`.

  it. The pitch-11 evidence that *is* here is the cross-check of the second reviewer's candidate, which
